# Game Laju Reaksi — Kimia Kelas XI

Versi ini sudah disiapkan sebagai game web:
- Saat link dibuka, siswa langsung masuk ke permainan dan soal pertama tampil otomatis.
- Tidak perlu membuka file lain.
- Tidak perlu instal aplikasi.
- 15 soal dipilih acak dari bank soal Laju Reaksi.
- Fitur bantuan: 50:50, Telepon Teman, dan Polling Penonton.
- Dapat dijalankan di HP, tablet, atau laptop.
- Musik latar mulai setelah interaksi pertama karena pembatasan autoplay browser.

## Cara online
Upload seluruh isi folder ini ke hosting statis seperti GitHub Pages, Netlify, atau Cloudflare Pages.
Pastikan `index.html` dan folder `assets` tetap berada pada struktur yang sama.

Setelah hosting aktif, bagikan URL `index.html`/domain tersebut kepada siswa.
